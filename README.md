
🛢️ YACIMIENTO AI
![YACIMIENTO AI](Portada.PNG)
Sistema inteligente para el análisis y monitoreo de pozos

YACIMIENTO AI es un prototipo desarrollado con Python, Pandas y Streamlit, orientado al análisis de datos históricos de pozos y a la identificación de situaciones que requieren atención.

El proyecto busca demostrar cómo el análisis de datos y herramientas de inteligencia artificial pueden utilizarse como apoyo para ordenar información, detectar anomalías y facilitar la toma de decisiones operativas.

🔎 ¿Qué hace?

* 📊 Analiza datos históricos de los pozos.
* ⚠️ Detecta anomalías.
* 🟠 Clasifica niveles de riesgo.
* 🎯 Establece prioridades de intervención.
* 💡 Genera recomendaciones.
* 📋 Presenta un resumen de los resultados.

🛠️ Tecnologías utilizadas

* Python
* Pandas
* Streamlit
* Análisis de datos
* Inteligencia artificial aplicada

🎯 Objetivo del proyecto

Desarrollar una herramienta de portfolio que permita explorar cómo los datos históricos de un yacimiento pueden transformarse en información útil para el seguimiento y la priorización de situaciones operativas.
